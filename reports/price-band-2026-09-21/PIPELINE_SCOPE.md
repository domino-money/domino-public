# PriceGuard band measurement: implemented pipeline and evidence limits

Read-only source review, 21 September 2026, checkout `b3f841f38948240a0cc05dd7ffc82b04ab5e1cb0`. No services, private configuration, keys, RPC requests or transactions were used for this note. The experiments below are proposed measurements, not results or a selected production band.

## Distinct windows and controls

- **Publish-time band:** immutable `maxDeviationBps`, measured in **sqrt-price bps**, compares attestation with publication-time slot0. If `q` is the published sqrt price and `s` the current sqrt price, acceptance is `s*(10000-d) <= q*10000 <= s*(10000+d)`. It is not the swap's slippage or execution impact limit.
- **Execution price bound:** owner-set `maxPriceImpactBps` is tested using the squared price ratio versus the anchor, with conservative floor/ceil arithmetic. [`checkSwapPrices`](../../contracts/src/DominoRoutingHelperV4.sol#L69) applies before execution and around swaps. Separate plan min/max sqrt prices and `maxSlippageBps`/minimum swap output also apply. A larger publish band does not relax these execution checks.
- **L2 freshness:** both guard and [`validateCompoundPrice`](../../contracts/src/DominoVaultReadHelper.sol#L148) require age **1–255 L2 blocks**, using ArbSys, even if the timestamp expiry is longer. Do not translate 255 blocks into seconds without measured block cadence. Guard timestamps are publisher claims on chain; the adapter additionally matches the canonical source header.
- **Time validity:** owner `maxObservationAgeSeconds` bounds age and plan deadline; guard expiry also applies. Adapter further requires observation expiry no later than source timestamp + 3600 seconds. These intersect; 3600 is not an effective one-hour promise. Source must precede the current block. Waiting for finality before execution is not imposed by the signer and may consume the entire recent-block window; receipt finalization is a separate later stage.
- **Cadence and deadlines:** owner `minimumIntervalSeconds` limits repeated execution. Planner sampling count/window/freshness, forecast horizon, buffer and price evidence are explicit settings without live defaults. Signer HTTP timeout defaults to 5 seconds, configurable up to 10; runner step has a 90-second total deadline, under a 300-second lease. These are timeout ceilings, not measured latency or permitted observation age. A 90-second step can exceed the 255-block freshness window.

## Executable measurement plan without real transactions

1. **Read-only mainnet series:** use only allowlisted reads (`eth_chainId`, header reads, `eth_call`, optionally relevant `eth_getLogs`). Record monotonic send/receive times, UTC, route label, explicit `latest`/`finalized` selection, L2 number/hash/timestamp, ArbSys number, pool ID and hash-pinned slot0. Recheck canonicality; retain timeout/error/missing samples. Measure RTT percentiles, head age, L2 cadence, skipped blocks, canonicality changes and finalized-head lag separately. No silent latest fallback.
2. **Delay replay on observed prices:** for each coherent source snapshot and subsequent observed snapshot, retain both elapsed seconds and L2 distance. Compute the exact minimum publish band `ceil(10000*abs(q_source-q_publish)/q_publish)`, directional distribution, sample count and coverage. Evaluate candidate bands against observed delays; distinguish unavailable/missing intervals from accepted/rejected observations. Also report squared price movement separately. This estimates drift-induced publication refusal for a **same-pool historical spot publisher**, not oracle accuracy, manipulation resistance or a production SLA.
3. **Local fork qualification:** pin source hashes and current compiled artifacts; deploy/impersonate only inside disposable Anvil. Replay candidate bands, measured delay distributions and boundary ages 1/255/256; independently vary publish-to-execute delay, observation expiry, owner impact/slippage and amount ceilings. Include GENERAL/NET, swap and successor paths. Record explicit revert stage/reason, actual gas, fee consumption, output and attack/control value deltas. Preserve independent axes for pre-publication versus post-publication manipulation. MockArbSys/local mining does not establish Nitro sequencing, congestion or inclusion latency.
4. **Production-source gate:** when an actual independent publisher source is selected, separately measure its identity mapping, timestamp lag, coverage and discrepancy against canonical pool spot before selecting the immutable band. A price already manipulated before a same-pool observation can pass a narrow band; favorable normal-drift percentiles cannot rule this out. Until this gate exists, label measured candidates as operational simulations and keep independent-source qualification unavailable.

The current **Mac ↔ SSH tunnel ↔ node** RPC route differs from the intended **runtime VM ↔ node/HTTPS** path. Report their timings separately. Tunnel RTT cannot predict VM HTTP/TLS, publisher signing/queueing, sequencer inclusion, execution queueing or finality latency. Those unmeasured terms must remain unknown or explicit fork scenario inputs, never zero. A short live sample supports a bounded observation window only; it cannot establish safe tail behavior or choose a universally safe immutable band.
